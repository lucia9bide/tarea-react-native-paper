# Consigna
Vamos a confeccionar la lista de libro con ayuda de la libreria react-native-paper y sus componentes personalizados: Card y TextInput.
A su vez, podemos armar de vuelta el arreglo books que usamos como mock data para el book-champions web.

## Debemos
  1. Crear una barra de búsqueda en la parte superior de la pantalla, que filtre los libros.
  2. Armar la lista de libros (con el componente FlatList) y que cada libro tenga su tarjeta con:
     - Titulo;
     - Autor;
     - Imagen;
     - Resumen.
  3. Armar dos botones: uno que nos muestre si el libro esta disponible o no y otro que permita ver el resumen completo.
